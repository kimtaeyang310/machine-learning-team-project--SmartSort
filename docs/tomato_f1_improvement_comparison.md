# 토마토 숙도 분류 F1 개선 방안 비교

작성일: 2026-10-16

## 요약 및 권고

현재 토마토의 `class_weight="balanced"`는 **유지**하는 편이 합리적입니다. 새 사진을 확보하기 어렵다면 여기에 **Train 내부에서만 증강을 적용하는 실험을 추가**해 비교하는 것을 권합니다. 둘 중 하나만 고르기보다 `기존 기준선` → `가중치 유지 + 증강`을 같은 그룹 교차검증으로 비교하고, 개선이 재현될 때 채택합니다.

증강은 실제 독립 표본을 늘리지 않습니다. 따라서 성능 개선을 보장하지 않습니다. 실행 시점 데이터 스캔 결과 토마토 Test는 52장이지만 `unripe 2 / ripe 30 / overripe 20`으로 불균형해, 소수 클래스 결과는 여전히 매우 불안정합니다.

## 확인한 현재 상태

- README에 기록된 전체 데이터 분할은 Train 2,086장, Test 491장입니다. 토마토 선택 모델은 SVM으로 **CV Macro F1 0.7592, Test Macro F1 0.3500, Test Accuracy 0.5273**입니다. 근거: `README.md`의 “과일별 모델 첫 실행 결과” 표.
- `src/train.py`에서 Logistic Regression, SVM, Random Forest, Decision Tree에 `class_weight="balanced"`가 설정되어 있습니다. KNN에는 적용되지 않습니다. Macro F1로 후보를 고르고, 동일한 과일별 `StratifiedGroupKFold` 분할을 사용합니다.
- `src/yolo_compare.py`는 YOLO 학습 시 `auto_augment=None`, `erasing=0.0`, `hsv_h/s/v=0.0`으로 명시해 주요 자동 증강을 꺼둔 상태입니다. 따라서 현재 YOLO 비교 경로도 증강을 이미 활용하고 있다고 볼 수 없습니다.
- 실제 데이터 로더가 스캔한 토마토는 Train 279장 / 34그룹, Test 52장입니다. Train 클래스 수는 `unripe 59 / ripe 80 / overripe 140`, Test는 `2 / 30 / 20`입니다. `fruit_labels.csv` 각 행은 이미지가 아니라 그룹 라벨이므로 행 수를 사진 수로 해석하지 않습니다.

## 두 방법 비교

| 방법 | 현재 적용 여부 | 기대 효과 | 한계·주의점 |
|---|---|---|---|
| `class_weight="balanced"` | 네 가지 모델에 적용 | 소수 클래스 오분류에 더 큰 비용을 줘 다수 클래스 편향을 완화 | 이미지나 개체 정보를 추가하지 않음. SVM의 가중치가 작을 때 특히 민감할 수 있음. 이미 설정되어 있으므로 이것만 추가하는 수정은 아님 |
| Train 전용 이미지 증강 | 현재 일반 특징 기반 파이프라인에 없음. YOLO의 대표 증강도 비활성화 | 제한된 원본에서 회전·촬영 조건 변화를 학습해 입력 변화에 대한 강건성을 높일 가능성 | 새 표본을 수집한 효과는 아님. 과한 색 변화는 숙도 단서를 훼손할 수 있음. 같은 원본의 파생본이 검증에 섞이면 누수 |
| 두 방법 병행 | 권장 비교안 | 비용 가중과 입력 다양성이라는 서로 다른 문제를 함께 보완 | 결과를 교차검증으로 확인해야 하며, 적은 원본 한계를 제거하지는 못함 |

## 권장 실험 설계

1. **기준선 보존:** 현재 파이프라인과 현재 토마토 Test를 고정하고, 기준 CV 및 Test 결과를 기록합니다. Test는 모델·증강 강도를 선택하는 데 쓰지 않습니다.
2. **학습 fold 안에서 증강:** 각 교차검증 fold에서 fold 학습 데이터의 토마토 이미지에만 증강을 생성합니다. 검증 fold와 최종 Test에는 원본만 둡니다. 같은 원본에서 만들어진 모든 파생본은 원본과 같은 `group_id`로 묶습니다.
3. **세 조건 비교:** (A) 기존 가중치 설정, (B) 기존 가중치 + 약한 증강, (C) 증강만 적용하고 가중치는 끈 대조군을 동일한 3-fold 그룹 분할에서 비교합니다. 핵심 지표는 Macro F1이며 숙도별 F1·Recall, fold별 점수와 편차도 같이 봅니다.
4. **보수적인 변형부터:** 작은 회전·이동·확대, 좌우 반전, 약한 밝기·대비 변화부터 시작합니다. 숙도 판별이 색에 의존할 수 있으므로 색조·채도 변화는 매우 약하게 제한하거나 우선 제외합니다. 이미지가 현실에서 가질 수 없는 모양·색을 만드는 변형도 피합니다.
5. **한 번만 최종 확인:** 내부 검증에서 일관된 이득이 보이는 설정을 고정한 뒤 Test를 확인합니다. 소수 클래스 Test 지원 수가 2장뿐이라는 한계를 보고서에 함께 적습니다. 추가적인 신뢰도 평가는 새 개체/촬영일을 모은 독립 Test가 생길 때 수행합니다.

### 파이프라인별 구현 시 주의

- **특징 기반 분류기:** 이 프로젝트는 먼저 이미지 특징을 계산한 뒤 SVM 등으로 학습합니다. 이미지 증강을 하려면 각 fold의 학습 원본을 변환한 뒤 그 변환 이미지에서 특징을 다시 추출해야 합니다. 이미 추출된 특징 행을 단순 복제하는 방식은 시각적 다양성을 만들지 않습니다. FeatureCache 키가 변환본을 서로 다른 이미지로 구분하는지도 확인해야 합니다.
- **YOLO 분류기:** Ultralytics 학습 설정에서 증강을 명시적으로 꺼두고 있습니다. 증강을 시험할 경우 지원되는 변환 설정을 바꾸되, 교차검증 검증 이미지와 Test에는 변환을 적용하지 않아야 합니다. YOLO 증강 설정을 바꾸는 실험은 특징 기반 모델의 증강과 별도 조건으로 기록합니다.

## 결론

별도 비교 실험에서 기준선 CV Macro F1은 0.7346, 가중치+증강은 0.7424였지만 표준편차가 커졌고 Test Macro F1은 0.4596에서 0.4412로 낮아졌습니다. 이 결과로 증강을 성능 개선으로 채택할 근거는 부족합니다. 현재는 `class_weight="balanced"`를 유지하고 증강은 후보로 보관하는 것이 합리적입니다. 소수 클래스 Test가 2장뿐이므로 Test 점수 변화만으로 효과를 단정해서는 안 됩니다. 상세 실행 결과는 `docs/tomato_augmentation_experiment.md`와 `outputs/tomato_augmentation_comparison/`을 참고하세요.
