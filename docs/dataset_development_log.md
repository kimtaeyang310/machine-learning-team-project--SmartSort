# 딸기 데이터셋 구축 개발 일지

## 딸기 데이터셋 누끼 처리 및 흰 배경 합성 결과

### 1. 목표

딸기 데이터셋의 이미지에서 딸기 과실을 배경과 분리한 후 누끼 처리하고, 흰색 배경에 합성하여 **과일 숙도 판별기 학습용 데이터**로 활용하고자 하였다.

---

### 2. 진행 내용

딸기 데이터셋을 활용하여 누끼 처리 및 흰 배경 합성을 여러 가지 방법으로 시도하였다.

#### 2-1. LLM 기반 이미지 처리

첫 번째로 **LLM 기반 이미지 처리**를 시도하였다.

원하는 작업 방식과 조건을 구체적으로 명령하여 누끼 처리를 요청하였으나, LLM이 기존 이미지를 직접 편집하기보다는 자체적으로 새로운 이미지를 생성하는 방식으로 처리되는 문제가 발생하였다.

명령어를 수정하여 여러 차례 시도하였지만 이후 **Client Error가 발생하여 원하는 방식으로 이미지 처리를 진행할 수 없었다.**

#### 2-2. Canva를 활용한 이미지 배경 제거

두 번째로 **Canva를 활용한 이미지 배경 제거**를 시도하였다.

그러나 Canva에서도 원본 사진의 딸기와 줄기, 잎, 주변 배경을 명확하게 구분하지 못하여 LLM을 이용한 처리와 유사하게 원하는 수준의 정확한 누끼 결과를 얻기 어려웠다.

#### 2-3. Python 기반 자체 누끼 처리

세 번째로 **Python 기반의 자체 누끼 처리 프로그램을 제작하여 처리**하였다.

이미지의 색상과 형태를 기준으로 딸기 영역을 검출하고 배경을 제거한 뒤 흰색 배경에 합성하는 방식으로 진행하였다.

그러나 실제 데이터셋에 적용한 결과 다음과 같은 문제가 발생하였다.

- 딸기 과실뿐만 아니라 줄기와 잎 일부가 함께 추출됨
- 반대로 딸기의 일부가 제거되는 현상 발생
- 딸기가 아닌 주변 배경의 일부가 딸기 영역으로 잘못 인식됨

---

### 3. 결과 및 원인 분석

여러 방법을 적용하였음에도 데이터셋 전체를 원하는 수준으로 누끼 처리하는 데에는 한계가 있었다.

이는 사용한 딸기 데이터셋의 이미지 특성이 주요 원인으로 판단된다.

해당 데이터셋은 한 장의 사진에 **여러 개의 딸기가 함께 촬영되어 있고, 딸기 과실과 줄기·잎이 서로 연결되어 있는 경우가 많았다.**

또한 촬영 환경에 따라 딸기와 주변 배경의 색상 및 형태가 유사하여 객체의 경계를 명확하게 구분하기 어려웠다.

특히 미숙 딸기의 경우 색상이 주변의 잎이나 식물과 유사하기 때문에 단순한 색상 기반 검출만으로는 정확한 분리가 어려웠다.

따라서 별도의 학습이나 세밀한 객체 분할 과정 없이 일반적인 이미지 처리 방법을 적용할 경우, **딸기 과실과 줄기·잎·배경을 정확하게 구분하는 데 한계가 있는 것으로 확인되었다.**

---

### 4. 최종 결과

결과적으로 현재 사용한 데이터셋에 대해 자동 누끼 처리를 적용하여 전체 이미지를 흰색 배경으로 변환하는 방법은 **학습 데이터로 사용할 만큼 일관되고 정확한 결과를 확보하지 못하여 중단하였다.**

특히 줄기 및 잎이 함께 추출되거나 딸기가 아닌 영역이 포함되는 문제가 반복적으로 발생하여, 해당 결과를 그대로 숙도 판별기 학습 데이터로 사용하는 것은 적절하지 않다고 판단하였다.

---

### 5. 향후 개선 방향

향후에는 다음과 같은 방법을 고려할 필요가 있다.

1. 처음부터 **딸기 과실과 배경의 경계가 명확한 이미지로 데이터셋을 구성**
2. 딸기 객체에 대한 **정확한 마스크를 직접 제작**한 후 이를 기반으로 학습 데이터 생성
3. 자동 누끼 처리 결과를 그대로 사용하지 않고 **수작업 검수를 병행**
4. 전체 데이터셋에 적용하기 전에 **소량의 이미지를 먼저 테스트**하여 결과를 확인한 후 전체 데이터셋에 적용
5. 필요할 경우 단순 색상 기반 검출이 아닌 **객체 분할(Segmentation) 기반 방법**을 검토

이번 작업을 통해 데이터셋의 촬영 환경과 객체 특성이 전처리 방법의 성능에 큰 영향을 미친다는 점을 확인하였다.
